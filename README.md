# SES Match — 営業向けモック

案件・人材の登録、資料取り込み、検索、説明付きマッチングを操作できるローカル用プロトタイプです。公開バージョン3のHTML / CSS / Vanilla JavaScriptをそのまま引き継いでいます。すべて架空データで、外部メール・AI・DB・実フォルダには接続しません。

## ローカル起動

ビルドやパッケージのインストールは不要です。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開いてください。

既存の開発環境では `npm run dev` も利用できます。表示されたLocal URLを開きます。起動先は `dist/` です。`npm run build` はJavaScriptの構文を確認して5ファイルを `build/` へコピーします。`npm run preview` はそのコピーを表示します。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `dist/index.html` | HTMLの入口、画面・ドロワー・通知の配置先 |
| `dist/style.css` | ネイビーのサイドバー、表、カード、レスポンシブ表示 |
| `dist/data.js` | 架空の18案件・10人材、案件資料10件・人材資料6件 |
| `dist/folder-import.js` | 共通のサンプルフォルダ指定・読み込み・解析 |
| `dist/app.js` | 7画面の切り替え、検索、登録編集、仮マッチング、保存 |
| `CODEX_HANDOFF.md` | 画面・挙動・デザインの引き継ぎ仕様 |
| `SOURCE_VERSION.txt` | 引き継いだ公開版のコミット情報 |
| `docs/project-requirements.md` | 従来のREADMEに記載されていた将来構想・要件 |
| `docs/local-verification.md` | ローカルでの確認結果 |

読み込み順はCSS → `data.js` → `folder-import.js` → `app.js`。スクリプトはモジュールへ変換していません。`dist/` はビルド生成物ではなく、編集・Git管理する正本です。既存のReact版の `src/`、`tests/` と関連依存は履歴参照用に保持しており、現在の画面からは読み込みません。`npm test` は旧React版サービスの検証です。

## 主な操作

- 人材一覧 →「案件を探す」→「AIマッチング実行」→ 推薦理由・懸念点の確認、候補保存。
- 案件／人材資料取り込み → サンプルフォルダ指定 → 読み込み → ファイル選択 → 解析 → 確認・修正 → 登録。
- 案件・人材一覧から検索、スキル・状態での絞り込み、新規登録、詳細・編集。

解析しただけでは案件・人材一覧へ登録されません。確認待ちから内容を確認して登録します。サンプルフォルダは疑似動作です。

変更はブラウザの `localStorage`（`ses-match-workspace-v1`）へ保存します。ローカルと公開サイト、ポートが異なるURLでは保存領域も別です。使い方ガイドの「初期データに戻す」から確認後にリセットできます。

公開サイトの変更・デプロイ・GitHubへのpushはこのローカル引き継ぎには含みません。
